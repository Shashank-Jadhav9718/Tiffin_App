# Tiffin Manager Monorepo (`tiffin-app`)

A modern, mobile-friendly **Premium Tiffin Attendance and Billing Manager** built as a monorepo containing a high-performance **FastAPI backend** and a responsive **React PWA frontend**.

---

## Folder Structure

```
tiffin-app/
├── backend/            # FastAPI python backend
│   ├── main.py         # REST Endpoints (CORS, daily-counts, billing, mark-paid, deactivate)
│   ├── Procfile        # Startup instructions for Render.com web dyno
│   ├── requirements.txt# Backend python dependencies
│   └── .env.example    # Configuration placeholders for Supabase
├── frontend/           # React + Vite + Tailwind CSS frontend (PWA)
│   ├── public/         # Manifest, logo icons, and PWA Service Worker (sw.js)
│   ├── src/            # App navigation shell and UI screens (Dashboard, Customers, Billing)
│   ├── index.html      # Google Fonts & mobile viewport viewport-fit settings
│   ├── tailwind.config.js # Color themes (Emerald primary) & DM Sans typography
│   └── .env.example    # Configuration placeholder for Vite API url
├── .gitignore          # Root level ignore settings (ignores .env, build files, node_modules)
├── render.yaml         # Render.com Blueprint configuration
└── vercel.json         # Vercel monorepo routing config
```

## 🗄️ Database Setup (Supabase)

To get started, execute the following SQL DDL commands inside your **Supabase SQL Editor** to create the required tables and constraints:

```sql
-- Enable UUID extension if not enabled
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 1. Create Customers Table
CREATE TABLE IF NOT EXISTS customers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT NOT NULL,
    phone TEXT,
    plan_type TEXT NOT NULL, -- e.g., 'Lunch', 'Dinner', 'Both'
    per_meal_rate NUMERIC NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Create Daily Logs Table
CREATE TABLE IF NOT EXISTS daily_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    customer_id UUID REFERENCES customers(id) ON DELETE CASCADE NOT NULL,
    date DATE NOT NULL,
    meal_type TEXT NOT NULL CHECK (meal_type IN ('Lunch', 'Dinner')),
    status TEXT NOT NULL CHECK (status IN ('Delivered', 'Canceled', 'Extra')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    CONSTRAINT unique_customer_date_meal UNIQUE (customer_id, date, meal_type)
);

-- 3. Create Monthly Bills Table
CREATE TABLE IF NOT EXISTS monthly_bills (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    customer_id UUID REFERENCES customers(id) ON DELETE CASCADE NOT NULL,
    month INTEGER NOT NULL CHECK (month >= 1 AND month <= 12),
    year INTEGER NOT NULL CHECK (year >= 2000),
    total_amount NUMERIC NOT NULL DEFAULT 0,
    status TEXT NOT NULL CHECK (status IN ('Paid', 'Unpaid')) DEFAULT 'Unpaid',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    CONSTRAINT unique_customer_month_year UNIQUE (customer_id, month, year)
);
```

## 🚀 Local Development Setup

### 1. Backend Setup

1. Navigate to the `backend/` folder:
   ```bash
   cd backend
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   # macOS/Linux:
   source .venv/bin/activate
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Configure environment variables. Copy `.env.example` to a new `.env` file and populate it with your Supabase credentials:
   ```bash
   cp .env.example .env
   ```
   Modify `.env` content:
   ```env
   SUPABASE_URL=https://your-supabase-id.supabase.co
   SUPABASE_KEY=your-anon-or-service-role-key
   ```
5. Run the local backend development server:
   ```bash
   uvicorn main:app --reload
   ```
   *The backend will boot up at `http://127.0.0.1:8000` (docs available at `/docs`).*

---

### 2. Frontend Setup

1. Navigate to the `frontend/` folder:
   ```bash
   cd ../frontend
   ```
2. Install npm packages:
   ```bash
   npm install
   ```
3. Configure environment variables. Copy `.env.example` to a new `.env` file and set the backend connection URL:
   ```bash
   cp .env.example .env
   ```
   Modify `.env` content:
   ```env
   VITE_API_BASE_URL=http://127.0.0.1:8000
   ```
4. Start the Vite hot-reloading development server:
   ```bash
   npm run dev
   ```
   *The frontend will run at `http://localhost:3000`.*

## ☁️ Cloud Deployment Configs

This monorepo is fully deployment-ready out of the box:

*   **Backend (Render.com)**:
    We've provided a `render.yaml` Blueprint file at the root. You can link your GitHub repo directly to Render.com and create a new **Blueprint Instance** using `render.yaml`.
*   **Frontend (Vercel)**:
    We've provided a `vercel.json` file configuring Vite and pointing build settings directly to the `frontend/` subdirectory. Simply connect your repo to Vercel and import as a Vite project.
